Este es el lede del frontmatter: un párrafo en body-lg que resume la pieza. Plantilla universal, no un post real: muestra todos los elementos para que cualquier post futuro herede el tratamiento del design system.

Por Camilo Ramírez · 5 min de lectura

TL;DR

Caja de resumen opcional vía frontmatter tldr. Si el campo está vacío, no aparece.

Nota lateral opcional (frontmatter aside): flota a la derecha en desktop, pasa a bloque en móvil.

Párrafo normal en body-lg con interlineado holgado. Dentro del texto pueden ir negritas, itálicas y enlaces con acento. El criterio de lectura es de 720px de ancho.

Heading 2 con franja

Heading 2 seguido de otro H2

Dos ## Heading 2 consecutivos respiran entre sí: el segundo deja aire arriba aunque no haya párrafo en medio.

Heading 3 sin franja

El ### Heading 3 es un subtítulo más discreto, sin franja, para subdividir dentro de una sección.

Cita de varios párrafos en Fraunces itálica con barra de acento. El primer párrafo plantea la idea, con una fuente enlazada y una palabra en negrita que deben ganar el estilo.

El segundo párrafo cierra el argumento, manteniendo el tratamiento sin cortarse entre bloques.

Lista desordenada con viñeta de franja:

  • Primer punto de la lista.
  • Segundo punto, con su marcador de franja.
  • Tercer punto.

Lista ordenada con números de acento, con una lista desordenada anidada:

  1. Primer paso.
  2. Segundo paso, con sub-puntos:
    • Sub-punto anidado uno.
    • Sub-punto anidado dos.
  3. Tercer paso, con negrita y enlace dentro del ítem.

Y una lista desordenada con una lista ordenada anidada:

  • Punto principal.
    1. Paso anidado uno.
    2. Paso anidado dos.
  • Otro punto principal.

Código en línea como npm install dentro de una frase, y un bloque de código:

const criterio = (ruido, señal) => {
  return señal.filter(x => x.importa);
};

Pull-quote grande en Fraunces itálica: la frase que ancla el artículo, separada del flujo con aire arriba y abajo.

Párrafo de cierre del cuerpo. A partir de acá viene el footer del post.
